# 使用說明

## 第一次打開渠成

按兩下專案資料夾裡的 `啟動渠成.cmd`。瀏覽器開啟後，請讓命令視窗保持開啟；它負責提供教材，也把進度存到本機。第一次使用時，先選目標職位、程度及每天的份量，之後都能改。

## 今天怎麼學？

1. 到「今天」，按時間或堂數設定份量。只剩半小時就選 30 分鐘，看過預覽再按「開始今天」。
2. 先做已到期的複習，再開新課。第一天還沒有知識點可複習，直接從第一堂開始。
3. 讀完範例，先自己動手，再對照檢查項目。把練習檔留在 `C:\dev\conduit-lab`，若 C 槽不允許寫入就改用 `D:\dev\conduit-lab`。不要把練習檔放進教材資料夾。回到課程標記完成，知識點就會進入複習排程。
4. 按「收工」看今天的紀錄；時間不夠也可以「提早收工」。先選明天**怎麼複習**，再選**複習哪些知識點**：全部到期、只複習今天學的、指定路線，或弱點優先。按「收工，明天見」儲存；明天開始前還能調整。

## 哪種複習適合我？

- **閃卡回想**：先不看提示，用自己的話回答，再翻面評分。想知道「不看筆記還記得嗎」時選它。
- **選擇題**：選答案後讀解說。兩個觀念老是混在一起時，拿它們來比較。
- **模擬面試**：按「朗讀並開始模擬」，在倒數內說出回答，再逐項對照要點。也可以寫下回答；不需要麥克風。
- **SQL 手寫**：用一道題複習一個或多個到期知識點。先寫、再檢查，最後確認建議的記憶評分。看解答或放棄會建議「忘了」；略過不改排程。沒有 SQL 題的知識點，可在本輪結束後改用閃卡。
- **動手練習**：重做課程任務，逐項檢查結果。看懂範例卻無法從空白開始時，就選這個。
- **混合**：交替練閃卡、選擇題、模擬面試與 SQL。平日想兼顧記憶和表達時選它；各方式的比重可在設定調整。

選擇題、模擬面試與動手練習若缺少對應題目，會改用閃卡；選擇方式時可先看涵蓋數量。

## 讓課文讀給你聽

按課程標題旁的「朗讀」，或直接點課文句子，就能從那裡開始。K 播放或暫停、J 回到上一句、L 到下一句，逗號和句點調整速度。看到程式碼時，播放器會先停下讓你看範例，再按「繼續」。回到同一課時會記住上次讀到的句子。

到「設定 → 朗讀」選台灣華語系統聲線、調整跟讀高亮，或開啟一次只顯示一段的「分段閱讀」。也可以讓閃卡與選擇題自動讀出題目。SQL 題按「朗讀題目」。想專心做一輪，可在設定打開專注計時，再從側欄（手機上是「更多」）開始 25 分鐘。

本機有預錄音檔時可優先用預錄聲線；還沒錄好的句子仍可由系統朗讀。

## 試錄自己的聲線

到「設定 → 朗讀 → 錄製我的聲線」，同意後逐句試錄。先試聽，再決定是否儲存；如果想重來，舊錄音會保留到你按「取代已儲存錄音」。讓每種語氣至少有一段 5–8 秒。錄音和試錄稿只存在本機，能在試錄頁逐段刪除，不會放入學習進度備份。

錄好後，告訴 Claude「用我的聲音」即可重新生成。試錄本身不會啟動合成，也不會切換現有的課文聲線。

## 實驗環境

先裝今天會用的工具，其他到對應模組再準備。每個實驗指定的版本與啟動方式，以課內說明為準。

- **從起步開始：** 準備 Python 和 VS Code。到「Git 版本管理」（`fd-git`）前，再裝 Git for Windows。
- **進入 Linux／容器：** 做 `fd-linux` 前先準備 WSL 2 Ubuntu；到 `fd-docker` 前裝 Docker Desktop，確認能啟動 Linux 容器。
- **進入 Java：** 到 `fd-java` 前準備課內指定的 JDK（基礎課用 JDK 25），到 Maven 課再準備 Maven。後續 Spark、Flink 等實驗可能指定不同的 JDK，按當堂說明選擇，不必替換全系統的預設。
- **大數據實驗一次只跑一組。** 視課程預留約 2–8 GB 可用記憶體，例如 Kafka 約 2 GB、本機 Spark 約 3–4 GB、Flink 約 5 GB，Airflow 需預留約 8 GB 給 Docker。這是給實驗的空間，不是整台電腦的總記憶體。開始前先停掉上一組服務，不足時先做課內的輕量練習。

如果「動手做」標有「實驗驗證範圍」，該通知列出的部分只依官方文件核對，沒有在編寫環境實跑。版本或輸出與範例不同時，先核對官方文件，再把實際版本和差異記進練習筆記。課內的離線 SQL 題仍可照常練習。

## 寫第一道 SQL

SQL 練習場用 DuckDB 在瀏覽器內執行。啟動渠成後不必上網，也不用另裝數據庫、DuckDB 或命令列工具。

渠成以「列」表示一筆紀錄（row），「欄」表示一個屬性（column）。中國大陸的題目常用「行」和「列」：同一張表，這裡寫「8 列、2 欄」，對方可能寫「8 行、2 列」。

在課程的「動手做」或「SQL 練習場」選一道題目。先看題目要幾欄、順序是否重要，再按「預覽 5 列」認識數據。按 Ctrl+Enter **執行**只看結果；按 Ctrl+Shift+Enter **檢查答案**才會記錄這次檢查。每次檢查都從原始數據開始，不會沿用之前的修改。若欄數不對，先看 SELECT；若列數不對，先看篩選與分組。提示可以逐個打開，通過後會看到解說。草稿會自動儲存，離開編輯器可按 Esc。

想自己出題，到「自由練習」選數據集。每個數據集各自保留草稿及最近 20 次執行的查詢；編輯中的數據庫不是永久存檔。按「重設」可從原始數據重新開始。題目很慢時，十秒後可按「停止」重新開始，不會清除草稿。

## 查找術語

在「題庫 → 術語」輸入英文、中文或別名，可看到大陸與台灣常見用法，以及第一次教這個詞的課程。「學習地圖」也能用術語找課。

## 進度在哪裡？換瀏覽器怎麼辦？

進度先存到目前的瀏覽器。用啟動檔開啟時，也會同步到專案的 `userdata/`。離開前可到「設定 → 數據」查看儲存狀態；若只有瀏覽器副本，清除網站數據就可能失去進度。

換電腦或瀏覽器前，先按「匯出備份」，把 JSON 檔另存一份。到新環境選「匯入備份」，核對筆數再按「取代並還原」。**還原會取代現有紀錄，不會合併**；想保留兩邊的進度，就先分別匯出。練習檔不在備份裡，請另外複製。

## 設定與快速鍵

在「設定 → 學習」調整日後的預設份量、路線及複習上限；「外觀」可改主題、字級、標題字體與閱讀寬度。離開輸入欄後，按 `/` 搜尋地圖、`?` 查看快速鍵。複習時按空白鍵或 Enter 翻面、1–4 評分，選擇題用 A–E 或 1–5；Ctrl+Z 復原最後評分，Esc 離開練習或關閉視窗。
